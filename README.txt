<::: HOW TO MAKE A WEBHOOKURL :::>
1. make your own discord server
2. go to edit channel on any of your channels (general)
3. go to integrations
4. press create webhook
5. copy the webhook url and it put in the macro

<::: HOW TO GET YOUR DISCORD SERVER ID :::>
1. go to user settings
2. search "developer"
3. go there and enable dev mode
4. now you can copy user id when you press on ur profile
